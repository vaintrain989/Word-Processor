# MobileDoc PWA

A local-first, mobile-optimised rich text processor with an automated tiered backup log engine.

## Features
- **WYSIWYG Rich Text Editing:** Smooth browser formatting controls for headings, lists, and emphasis types.
- **Tiered Auto-Save Logic:** Saves automatically every minute. Retains every single minute block for the first 15 minutes, then condenses down to space-efficient hourly and daily historical logs up to a 30-slot rolling max.
- **Live Document Analytics:** Integrated tracking panel providing character count, word totals, and reading runtime dynamics.
- **PWA Ready:** Fully installable to your mobile device or desktop layout.
